# Photonic Ising Machine Simulation

This project simulates a photonic Ising machine that uses a Spatial Light Modulator (SLM) to solve optimization problems. The simulation is implemented in Python and uses the HOLOEYE SLM Display SDK for phase mask generation.

## Project Overview

The core of the project is to find the ground state of an Ising Hamiltonian by using a simulated annealing algorithm. The spin interactions are encoded into phase masks displayed on an SLM, and the system's energy is measured to guide the annealing process. The project includes scripts for generating these phase masks, compensating for experimental imperfections like Gaussian beam profiles, and running the simulated annealing loop.

## File Descriptions

### Python Scripts

- **`beam_comp.py`**: This is the main script for generating SLM phase masks. It takes an interaction matrix `J`, decomposes it into Mattis Hamiltonians, and computes the corresponding phase patterns. It also includes functionality to compensate for non-uniform beam intensities (e.g., a Gaussian beam profile) to ensure accurate interaction strengths.

- **`beam_comp_multithreaded.py`**: A multi-threaded version of `beam_comp.py` that parallelizes the phase mask generation process. This is useful for large systems where generating masks for each eigenmode can be computationally intensive.

- **`vectorized_beam_comp.py`**: A performance-optimized version of `beam_comp.py` that uses vectorized NumPy operations to accelerate calculations. This script is ideal for scenarios requiring high-speed mask generation.

- **`simulated_annealing.py`**: This script orchestrates the simulated annealing process. It uses the phase masks generated by `beam_comp.py` and interacts with the HOLOEYE SLM Display SDK to display them. It also contains a placeholder for a hardware measurement function to read the system's energy.

- **`photonic_annealing.py`**: A comprehensive script that manages the entire Photonic Ising Machine experiment. It integrates hardware control (SLM and photodiode), Mattis Hamiltonian decomposition, and the simulated annealing loop. This script is designed for a real experimental setup and relies on the proprietary HOLOEYE SLM Display SDK.

### Jupyter Notebooks

- **`Photonic_SA.ipynb`**: A Jupyter notebook for running the photonic annealing simulation. It loads the interaction matrix from `MC100.npz`, initializes the hardware using the HOLOEYE SDK, and runs the simulated annealing algorithm.

- **`Phase encoding SPIM.ipynb`**: This notebook focuses on the phase encoding scheme for the Spatial Photonic Ising Machine (SPIM). It provides a step-by-step guide on how spin states are encoded into phase masks and includes visualizations of the resulting phase patterns.

- **`Intensity profile.ipynb`**: A utility notebook for analyzing the intensity profile of the beam. This is important for accurately compensating for beam inhomogeneities in the phase mask generation.

### Data Files

- **`MC100.npz`**: A data file containing the interaction matrix `J` for a 100-spin system. This is used as input for the simulated annealing algorithm.

## Setup Instructions

1. **Install Dependencies**: Make sure you have the required Python libraries installed:
   - `numpy`
   - `matplotlib`
   - `pyserial`
   - `jupyter`

2. **HOLOEYE SLM Display SDK**: This project depends on the proprietary HOLOEYE SLM Display SDK (`hedslib`). The SDK is not included in this repository and must be obtained from HOLOEYE. Once installed, update the `sdk_install_path` variable in `photonic_annealing.py` to point to your SDK installation directory.

3. **Running Simulations**:
   - Use the Jupyter notebooks (`Photonic_SA.ipynb`, `Phase encoding SPIM.ipynb`) to run simulations and visualize results.
   - The Python scripts can be run from the command line, but they are primarily designed to be used within the notebooks or a larger experimental control script.
